# 4. Objectives

| # | Objective | Supporting requirements |
|---|---|---|
| O-1 | Collect accurate periodic measurements of temperature, pressure, sunshine, rainfall, wind speed and wind direction at a remote site | UR-01 |
| O-2 | Reduce raw readings locally into validated summaries so that satellite bandwidth is used sparingly | UR-02, UR-03 |
| O-3 | Consolidate the output of every station into one processed, analysable, permanently archived data set | UR-04, UR-05, UR-06 |
| O-4 | Let operators see the health of every station without travelling to it | UR-07, UR-08, UR-10, UR-11 |
| O-5 | Keep the station powered and protect its power hardware without human help | UR-09, UR-12, UR-13 |
| O-6 | Allow the station to be administered and updated remotely, without a shutdown | UR-14, UR-15 |
| O-7 | Keep collecting data through partial hardware failure | UR-16, UR-17 |
| O-8 | Operate indefinitely in a location with no infrastructure and no staff | UR-18 |

## Success criteria

- A station continues to record and transmit data across a full deployment period
  with no site visit.
- A failed instrument is detected, reported and worked around automatically.
- A software defect can be corrected from the central site over the satellite link.
- No observation is lost because the archive was unavailable.
