# 5. Stakeholders

| Stakeholder | Interest in the system | Requirements they drive |
|---|---|---|
| **Meteorologists / weather forecasters** | Need timely, trustworthy observations from regions with no coverage, and a long historical record to analyse | UR-01, UR-05, UR-06 |
| **Data analysts / climate researchers** | Query the archive for long-run trends; care about completeness and consistency of the record | UR-04, UR-05, UR-06 |
| **Station maintenance engineers** | Must know which station is failing and why, and want to fix what they can from the office | UR-07, UR-08, UR-10, UR-11, UR-14, UR-15 |
| **System administrators / operators** | Control station parameters, schedule updates, manage the central server | UR-14, UR-15 |
| **Software development team** | Build the embedded, server and maintenance software; need requirements that can be verified | All |
| **Field service technicians** | Perform the rare physical visit; want faults diagnosed before they travel | UR-11, UR-16 |
| **Funding body / meteorological agency** | Pays for the network; wants maximum uptime per station and minimum field visits | UR-17, UR-18 |
| **Instrument and hardware suppliers** | Supply sensors, batteries, wind generator and satellite transceiver against a fixed specification | UR-09, UR-12, UR-13 |
